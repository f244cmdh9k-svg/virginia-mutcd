# Decision Summary

| Workflow | Screening rule |
|---|---|
| [Establish authority and interpret a provision](capabilities/authority.md) | Resolve the controlling authority, edition, and statement class before applying device criteria. |
| [Choose an official MUTCD request pathway](capabilities/official-requests.md) | Match the requested outcome to the correct Part 1B procedure and prepare the evidence for the responsible authority. |
| [Review a permanent sign schedule](capabilities/sign-review.md) | Pair the exact sign-family provision and size table with Chapter 2A's application, placement, and maintenance checks. |
| [Screen horizontal-curve warnings](capabilities/curve-warning.md) | Select the Virginia curve chart and differential threshold using the site classification and established advisory speed. |
| [Review pavement markings and maintenance](capabilities/marking-review.md) | Select markings by lane function and apply Virginia-specific installation and maintenance criteria. |
| [Calculate a permanent lane-reduction taper](capabilities/lane-reduction.md) | Select the §3B.12 formula by speed limit and calculate with the greater of the limit and 85th-percentile speed. |
| [Screen a pedestrian crossing and supplemental devices](capabilities/pedestrian-crossing.md) | Assess crossing conditions first, then check each candidate treatment's application and restrictions. |
| [Screen conventional traffic signal warrants](capabilities/signal-warrants.md) | Evaluate applicable warrants, then separately document site-specific justification and alternatives. |
| [Audit signal design, operation, and accessibility](capabilities/signal-design.md) | Review signal design against the equipment, movement, indication, timing, and accessibility clauses that apply. |
| [Review device uniformity and visibility for driving automation](capabilities/automation.md) | Prioritize device consistency and serviceability using the Part 5 guidance and the device's governing chapters. |
| [Identify the governing temporary traffic control manual](capabilities/work-zone.md) | Route applicable Virginia temporary traffic control to the separate VWAPM and verify the project transition record. |
| [Develop or review a school route and crossing plan](capabilities/school-area.md) | Base school treatments on the documented route network, crossing conditions and responsible officials' assessment. |
| [Prepare a grade-crossing diagnostic review](capabilities/grade-crossing.md) | Use the Diagnostic Team study to connect sight distance, storage, controls and preemption. |
| [Review bicycle traffic control at conflict points](capabilities/bicycle-facility.md) | Classify facility and movement, then check the conflict-point markings, signs and applicable legal constraints. |

Use each workflow's conditions, exceptions and citations for an actual finding.
