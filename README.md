# Virginia MUTCD v11.0 Codex Skill

Use this skill to review Virginia traffic-control questions and plans against the Virginia MUTCD. It contains fourteen workflows for source applicability, signs, markings, signals, school areas, grade crossings, bicycle facilities, and related topics.

Start with [SKILL.md](SKILL.md). The skill includes a [source locator](resources/source-locator.md), a [glossary](references/glossary.md), and a [decision summary](references/cheatsheet.md).

The distillation uses the January 2026, Version 11.0 edition. Verify the applicable edition, official graphics, project facts, and agency decisions before using a finding in a design or approval. Part 6 concerns the separate Virginia Work Area Protection Manual. [Official Virginia incorporation register](https://law.lis.virginia.gov/admincode/title24/agency30/chapter315/section9999/).
